# QuotTracker AI

Quotation and procurement request tracking with spreadsheet imports, PDF
extraction, AI-powered search, and Excel export.

See [QuotTracker_FINAL/README.md](./QuotTracker_FINAL/README.md) for local
installation, configuration, tests, and deployment requirements.

The application does not create demo or seed records. Configure administrator
credentials and a session secret before starting it. Never commit `.env`,
database files, uploads, or customer documents.
